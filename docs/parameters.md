# 参数说明

本文档按参数的作用阶段分类，标注默认值与调节建议。

> 约定：所有参数名使用下划线写法，例如 `--no_resume`、`--compare_all_is_energies`、`--cpus`。复制命令时请连同下划线一起复制。

---

## 一、必填参数（5 个）

每次运行都必须在命令行中明确指定路径，缺一即报错退出。

| 参数 | 作用 |
|---|---|
| `--query_mgf` | 样本中测得的实验质谱数据（MGF 格式） |
| `--edbms1_csv` | 实验谱库 EDB 的一级质谱（MS1）索引表 |
| `--isms1_csv` | 预测谱库 ISDB 的一级质谱（MS1）索引表 |
| `--edbms2_json` | 实验谱库 EDB 的二级质谱（MS2）谱库（JSON） |
| `--isms2_json` | 预测谱库 ISDB 的二级质谱（MS2）谱库（JSON） |

文件格式见 [`database_format.md`](database_format.md)。

## 二、科学参数（决定鉴定精度）

### `--ms2_ppm_strict`

- **默认值**：20.0
- **作用**：决定第一轨（严格通道）的 MS2 碎片对齐窗口宽度。程序会按此值计算第二轨（兜底通道）为它的 5 倍（默认 100.0 ppm）。
- **调节建议**：仪器刚校准、状态好时可收紧到 10.0；存在明显质量轴漂移时可放宽到 30.0。
- **注意**：调节后，输出中的 `extraction_track` 标注应当随之反映实际窗口值。

### `--noise_threshold`

- **默认值**：0.01（相对基峰强度的 1%）
- **作用**：上游谱图清洗的截断线。相对强度低于基峰 1% 的碎片峰在比对前被剔除。
- **调节建议**：觉得清洗过狠、伤了真峰，可调至 0.005（0.5%）；谱图杂乱时上调至 0.05（5%）。

### `--ppm_tol`

- **默认值**：10.0
- **作用**：MS1 母离子初筛的质量容差。程序在实验 MS1 质量的 ±10 ppm 范围内检索候选。
- **计算方式**：`tol = pm × ppm_tol / 10⁶`（`pm` 为母离子质量）。以 m/z 500.000 为例，10 ppm 对应 ±0.005 Da。
- **为什么用相对值**：不同 m/z 区间的绝对误差不同，ppm 可自适应不同大小的分子。质量越大，允许的绝对误差越大。

### `--min_peaks`

- **默认值**：3
- **作用**：准入门槛。某候选与 Query 匹配上的有效碎片少于该值时，直接视为假阳性淘汰，不参与后续综合打分，无论其算法得分多高。
- **调节建议**：默认 3 偏宽松，结果不够严谨时可提到 5。

## 三、系统与性能参数

### `--cpus`

- **默认值**：8
- **作用**：并行计算调用的 CPU 线程数。
- **调节建议**：设为服务器核数减 2，留余量给操作系统，例如 72 核机器用 `--cpus 70`、128 核用 `--cpus 126`。

### `--output`

- **默认值**：`ms_tournament_results`
- **作用**：所有谱图文件夹、CSV 表格、镜像对比图的输出根目录。目录不存在时自动创建。

## 四、运行模式开关（布尔值，写上即激活）

这些参数不需要赋值，在命令行中写出参数名即生效。

### `--no_resume`

- **默认状态**：关闭（即启用断点续传）
- **作用**：强制覆盖重跑。不加此参数时，程序遇到此前已完成的 Query 会直接跳过；加上后，忽略既有结果，全部按当前规则重算。
- **使用时机**：规则或谱库版本更新后，必须加此参数，否则会沿用旧结果。

### `--compare_all_is_energies`

- **默认状态**：关闭（仅比对 e0）
- **作用**：多碰撞能量检索开关。ISDB 中每个化合物通常有 e0、e1、e2 三种碰撞能量的预测谱。不加时只算 e0 以节省时间；加上后对三种能量分别打分，自动取最高分。
- **代价**：耗时约为单能量的数倍，适合疑难谱图的深度攻关。

## 五、两种典型用法

**A. 常规筛查（侧重速度）** —— 用于大批量初步筛选：

```bash
python ms_tournament.py \
  --query_mgf  /path/to/sample.mgf \
  --edbms1_csv /path/to/db/edb_ms1.csv \
  --isms1_csv  /path/to/db/is_ms1.csv \
  --edbms2_json /path/to/db/edb_ms2.json \
  --isms2_json  /path/to/db/is_ms2.json \
  --output /path/to/results/fast \
  --cpus 64 \
  --ppm_tol 10.0 \
  --ms2_ppm_strict 20.0 \
  --noise_threshold 0.01 \
  --min_peaks 3
```

**B. 深度精准挖掘（侧重准确度）** —— 用于少量疑难物质的攻关，加上 `--compare_all_is_energies`：

```bash
python ms_tournament.py \
  ... \
  --output /path/to/results/deep \
  --cpus 126 \
  --compare_all_is_energies
```

## 六、已知行为与限制

以下两处已通过实际输出核实，使用前需知：

1. **`extraction_track` 的标签是固定字符串** —— 实际输出为 `Strict_20ppm` 与 `Fallback_100ppm`，其中的 `20` 与 `100` 写死在代码里。若通过 `--ms2_ppm_strict` 调整了严格通道容差（例如改为 15.0），该列仍显示 `Strict_20ppm`，与实际窗口不符。判定匹配质量时应以参数取值而非该列文字为准，或按需修改源码使标签动态生成。

2. **断点续传检查的目录尚未确认** —— 原文档提到“自动检查 `results_v6` 文件夹”，而 `--output` 的默认值为 `ms_tournament_results`。若实际检查的是固定路径而非 `--output`，那么更换输出目录时续传行为会与预期不同。建议首次运行时观察日志确认。
